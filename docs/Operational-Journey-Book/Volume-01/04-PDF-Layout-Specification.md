# PDF Layout Specification

- Format: A4 portrait, 18 mm side margins.
- Typography: DejaVu Sans family; strong hierarchy and high-contrast body text.
- Brand palette: ABSHealthcareLite navy `#12304A`, clinical teal `#0F8B8D`, Doctors Point green `#2E7D5A`, warm evidence gold `#D9A441`.
- Screenshot pages: one uncropped image per page, aspect-ratio preserved, surrounded by white space.
- Metadata: step, business goal, actor, route, explanation, system response, module, Browser UAT, evidence ID and QC status.
- Navigation: table of contents, chapter dividers, running header, running footer and page number.
- Accessibility: captions are meaningful; colour is never the only status signal; body type is at least 9 pt.
- Export: original PNG pixels embedded using lossless image data; no placeholder art.
